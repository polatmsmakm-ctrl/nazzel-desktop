# نزّل للكمبيوتر (ويندوز)

نفس تطبيق «نزّل» حق الآيفون، بس للكمبيوتر: نفس محرك التحميل، ونفس الواجهة العربية والميزات، ومعه ffmpeg.

## التحميل

آخر نسخة دائماً:

```
https://github.com/polatmsmakm-ctrl/nazzel/releases/download/windows-latest/Nazzel-Setup.exe
```

أو `Nazzel-Portable.zip` تفكه وتشغّل `Nazzel.exe` بدون تثبيت.

> يحتاج Windows 10 أو 11 (64-bit) مع Microsoft Edge WebView2 (موجود في ويندوز 11 وأغلب أجهزة ويندوز 10).

## الميزات

- تحميل من يوتيوب، تيك توك، إنستقرام، إكس، سناب، فيسبوك ومئات المواقع: فيديو بأعلى جودة، صوت MP3، صور، GIF، أي ملف
- طابور تحميل مع إيقاف واستكمال (حتى لو سكّرت البرنامج)، وعدة اتصالات للملف
- لما تنسخ رابط من أي مكان، يقترح عليك تنزيله
- مكتبة ملفات مع مشغّل وترجمة (توقيت، حجم، لون، خط)، «كمّل المشاهدة»، قوائم تشغيل
- تحويل MKV إلى MP4، تحويل إلى MP3، ضغط للواتساب، صنع GIF، لقطات، مونتاج مع موسيقى
- كل الترجمات العربية للأفلام والمسلسلات، وتنزيل الأفلام والمواسم من ستريميو
- مساعد Gemini: يجاوب، يلخص فيديوهات يوتيوب، ينفّذ أوامر («نزّل آخر ٥ مقاطع من القناة»)
- ترجمة عربية وتفريغ نصي بالذكاء الاصطناعي
- فك ZIP و 7z و TAR، ومعلومات ملفات IPA
- متابعة القنوات: الجديد ينزل لحاله

## للمطورين

```
pip install -r requirements.txt
python run.py            # البرنامج
python run.py --browser  # الواجهة في المتصفح
python -m nazzel_desktop.selftest
```

GitHub يبني `Nazzel-Setup.exe` تلقائياً مع كل تحديث على فرع `windows`.
